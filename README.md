# Pinplore 전시용 프로토타입

이 폴더를 GitHub Pages에 그대로 올리면 동작해요.
한 번 열고 나면 화면·이미지·폰트가 기기에 저장되어 **와이파이가 끊겨도** 실행돼요.

## 1. GitHub Pages에 올리기 (약 5분)
1. GitHub에서 새 저장소를 만들어요. 이름 예: `pinplore`. Public으로 만들어야 무료 Pages를 쓸 수 있어요.
2. 저장소의 **Add file → Upload files**에 이 폴더 안의 파일과 폴더를 전부 끌어다 놓고 **Commit changes**를 눌러요.
   - `img`, `fonts`, `vendor` 폴더도 꼭 함께 올려요.
   - `.nojekyll` 파일도 함께 올려요. Finder에서 숨김 파일이라 안 보이면 `Cmd + Shift + .`을 눌러요.
3. **Settings → Pages**로 가서 Source를 `Deploy from a branch`, Branch를 `main` / `/(root)`로 두고 **Save**를 눌러요.
4. 1~2분 뒤 `https://<아이디>.github.io/pinplore/` 주소가 생겨요.

## 2. 전시 기기에 설치하기 (주소창 없이 앱처럼)
**iPhone (Safari)**
1. Safari로 주소를 열고, 지도가 있는 화면까지 한 번씩 둘러봐요. 오프라인용 저장이 이때 끝나요.
2. 공유 버튼 → **홈 화면에 추가**를 눌러요.
3. 홈 화면의 Pinplore 아이콘으로 실행하면 주소창 없이 전체 화면으로 떠요.
4. 관람객이 앱을 나가지 못하게 하려면 **설정 → 손쉬운 사용 → 사용법 유도**를 켜고, 앱 안에서 측면 버튼을 세 번 눌러 시작해요.

**Android (Chrome)**
1. Chrome으로 주소를 열고 메뉴 → **앱 설치**(또는 홈 화면에 추가)를 눌러요.
2. 설치된 앱은 주소창 없이 전체 화면으로 실행돼요.
3. 고정하려면 **설정 → 보안 → 앱 고정**을 켜요. 더 단단히 잠그려면 Fully Kiosk Browser 같은 키오스크 앱을 쓰세요.

## 3. 전시 운영 팁
- **자동 처음으로**: 90초 동안 아무도 만지지 않으면 시작 화면으로 돌아가요.
  시간은 `index.html` 안의 `window.KIOSK={idle:90}` 숫자로 바꿔요. 0이면 꺼져요.
- **화면 켜짐**: 앱이 화면 켜짐 유지를 요청하지만, 기기 설정의 자동 잠금도 "안 함"으로 두세요.
- **지도**: MapLibre + OpenFreeMap(Positron) 실시간 지도예요. 처음 본 영역의 지도 타일은 기기에 저장돼요.
  인터넷이 없을 때 저장되지 않은 영역은 Figma 지도 이미지로 대신 보여요.
- **업데이트**: 파일을 새로 올린 뒤, 기기에서 앱을 완전히 껐다 켜면 새 버전으로 바뀌어요.
